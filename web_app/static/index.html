📥 Módulo de Entradas (Slot 1: 20 Bytes In - Visão ➔ CLP)

Byte Offset Endereço PLC Tipo de Dado Nome da Variável Descrição / Função
0..1 %IW0 UINT g_StatusFlags Bits de Status (Bit 0: Ready, Bit 1: Target, Bit 2: Pass, Bit 5: Trigger Ack)
2..3 %IW2 UINT g_ClassID ID da Classe (1 = Peça Vermelha, 2 = Verde, 3 = Azul)
4..5 %IW4 UINT g_ObjectCount Quantidade total de objetos inspecionados na foto
6..9 %ID6 REAL g_PosX_mm Posição X do centroide em milímetros no mundo real
10..13 %ID10 REAL g_PosY_mm Posição Y do centroide em milímetros no mundo real
14..17 %ID14 REAL g_Angle_deg Ângulo de rotação da peça em graus (-180.0° a +180.0°)
18..19 %IW18 UINT g_ActiveRecipe ID da receita em execução ativa no Raspberry Pi

📤 Módulo de Saídas (Slot 2: 6 Bytes Out - CLP ➔ Visão)

Byte Offset Endereço PLC Tipo de Dado Nome da Variável Descrição / Função
0 %QB0 BYTE / USINT g_TriggerCmd Comando de disparo (1 = Tirar foto e processar inspeção)
1 %QB1 BYTE / USINT g_RecipeCmd Comando de troca de receita enviada pelo CLP
2 %QB2 BYTE / USINT g_ModeCmd Modo de operação (0 = Automático, 1 = Calibração)
3 %QB3 BYTE / USINT g_ResetFault Comando de Reset de Alarmes/Falhas da visão
4..5 %QW4 WORD / UINT g_Reserved Reservado para expansão futura

🚩 Mapeamento de Bits de StatusFlags (UINT)

  • Bit 0 (0x0001): STATUS_FLAG_READY - Sistema de Visão Pronto
  • Bit 1 (0x0002): STATUS_FLAG_TARGET_FOUND - Objeto Localizado
  • Bit 2 (0x0004): STATUS_FLAG_PASS - Inspeção Aprovada (OK)
  • Bit 3 (0x0008): STATUS_FLAG_FAIL - Inspeção Reprovada (NOK)
  • Bit 4 (0x0010): STATUS_FLAG_PROCESSING - Inspeção em Processamento
  • Bit 5 (0x0020): STATUS_FLAG_TRIGGER_ACK - Confirmação do Disparo (Handshake)

🎨 Mapeamento de Classes de Cor (ClassID)

  • 🔴 Classe 1: Peça Vermelha (HSV 0..10 / S:100..255 / V:100..255)
  • 🟢 Classe 2: Peça Verde (HSV 35..85 / S:100..255 / V:100..255)
  • 🔵 Classe 3: Peça Azul (HSV 100..130 / S:100..255 / V:100..255)

🌐 Configuração de Rede do Raspberry Pi

Interface Ethernet (eth0)

ℹ️ Orientações para Conexão com o CLP Altus

O Raspberry Pi deve estar na mesma faixa de IP do CLP Altus NX325/XP325 (por exemplo, CLP em 192.168.0.10 e Raspberry Pi em 192.168.0.231 com máscara 255.255.255.0).
